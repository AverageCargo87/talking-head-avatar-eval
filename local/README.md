# Local talking heads: Wan2.1 InfiniteTalk on a 12 GB RTX 3060

Free, local, offline talking-head video for the lesson's two AI-generated hosts, including both
of them in one shot. ComfyUI is driven headlessly through its HTTP API; no window is opened.
This was an experiment of 19-20 November 2026: the clips in `samples/infinitetalk/` are its
output, and they are research material, not something the live lessons use.

| | |
|---|---|
| Model | Wan2.1 I2V 14B 480p (GGUF Q4_K_M) + InfiniteTalk Single/Multi (GGUF Q8) |
| Speed-up | lightx2v step-distillation LoRA: 6 sampling steps at cfg 1 |
| Attention | SageAttention: **57 s per step** vs 90 s with PyTorch SDPA (about 76 s with two people) |
| One host, 30 s of video | about **65 min** |
| One host, 10 s | 19-25 min |
| Two hosts in one shot, 17 s | 48 min |
| Two hosts in one shot, 58 s | about **2.6 h** (21 sampler windows) |
| Memory | 30 transformer blocks swapped to RAM; the server with the Q4 model takes about 18 GB of 32 GB RAM |

All timings are from the project notes of 2026-11-19/20 on the RTX 3060 12 GB.

## Files

| file | what it does |
|---|---|
| `comfy_infinitetalk.py` | builds the InfiniteTalk graph (single or two speakers, optional masks), queues it, polls, stitches frames + audio with the A/V shift; `--check` validates a graph, `--dump-graph` writes it without a server |
| `workflows/*.api.json` | the two graphs in ComfyUI API format (generated by the script; a test keeps them in sync) |
| `weights.txt`, `WEIGHTS.md` | what to download and from where (links only, nothing redistributed) |
| `download_weights.py` | resumable parallel ranged downloader for `weights.txt` |
| `split_dialogue.py` | one dialogue recording -> one track per speaker, silence where the other talks |
| `syncnet_offset.sh` | SyncNet confidence and audio offset through a LatentSync checkout |
| `stitch_frames.sh` | mux frames that ComfyUI finished after the client gave up |

## Run

```bash
# 1. ComfyUI with the WanVideoWrapper, KJNodes and VideoHelperSuite custom nodes, weights from WEIGHTS.md
python main.py --listen localhost --port 8188          # inside your ComfyUI checkout

# 2. one host
python local/comfy_infinitetalk.py --img host-640.png --audio host-10s.wav --w 640 --h 640 \
  --name host-10s --out-dir out --comfy-input /path/to/ComfyUI/input \
  --prompt "A young woman ... talks to the camera in a calm, friendly and warm manner, like an experienced TV presenter ..."

# 3. two hosts: per-speaker tracks first, then the multi-speaker graph with explicit masks
python local/split_dialogue.py dialogue.wav turns.json /path/to/ComfyUI/input
python local/comfy_infinitetalk.py --img two-hosts-832x480.png --audio lena.wav --audio2 artem.wav \
  --mix dialogue.wav --masks mask-lena.png,mask-artem.png,mask-background.png \
  --w 832 --h 480 --audio-scale 0.75 --name two-hosts --out-dir out --comfy-input /path/to/ComfyUI/input
```

## Pitfalls that cost real hours

1. **Pin transformers 4.57.6.** transformers 5.x breaks the wav2vec audio encoder that
   InfiniteTalk uses (`hidden_states` comes back as None). The working set was transformers
   4.57.6 with diffusers 0.35.2 and peft 0.17.1 (newer diffusers wants huggingface_hub 1.x).
2. **At cfg = 1 the negative prompt does nothing.** The distillation LoRA runs at cfg 1, so only
   the positive prompt steers. The first prompt asked for "lively facial expressions, gentle head
   movements" and got exactly that; a "calm TV presenter" prompt cut frame motion from 2.25 to 1.74
   (1.67 with `--audio-scale 0.75`).
3. **No negations in the prompt.** "does not smile, nod or gesture" made the hosts smile and nod:
   the T5 encoder picks up the verbs. Describe the wanted state instead ("keeps the head steady").
4. **The audio is 80 ms late.** SyncNet reported -2 frames on both 30 s hosts; with the audio
   started 0.08 s earlier it reads 0 (confidence 7.68 -> 7.78 on one host). `--av-shift 0.08` is
   the default. This repository's own offset metric sees the same 2-frame change (see
   [docs/METRICS.md](../docs/METRICS.md)).
5. **Two speakers need your own masks.** In the wrapper version used, the automatic "left half /
   right half" masks were created after the sampler had already read `ref_target_masks`, which
   crashed it. Pass `--masks` (PNG, white = person, red channel): `LoadImageMask` -> `BatchMasksNode`
   -> `ref_target_masks`. A multi-page TIFF does not work: `LoadImage` reads only the first page.
6. **One generation at a time.** The GPU and 18 GB of RAM are taken; a second job or a LatentSync
   pass alongside it runs out of memory (a 9 s LatentSync job took 10 minutes next to ComfyUI).
   Free the models first: `POST /free {"unload_models": true, "free_memory": true}`.
7. **Bypass the system proxy for localhost.** The workstation ran a VPN client with a system
   proxy; the script talks to ComfyUI through a proxy-less opener (and `curl --noproxy '*'` for
   manual calls), so local requests never take that detour.
8. **Use the safetensors wav2vec2 build** (`Kijai/wav2vec2_safetensors`); the local Hugging Face
   cache of the original Chinese wav2vec2 model held only refs, no weights.
9. **SyncNet is an aid, not a judge.** A silent InfiniteTalk base plus a LatentSync lip pass scored
   higher SyncNet confidence (7.3-7.5) and looked worse: "uncanny valley, the lips miss, they look
   sad". The accepted recipe is InfiniteTalk alone; tune the prompt, `--audio-scale`, the seed and
   the audio the model hears (the clip keeps the original voice).
